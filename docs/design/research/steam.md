# Steam ストア（store.steampowered.com、デスクトップ Web）の観察メモ

**この内容は Claude の学習データ（記憶）に基づく。実物のページは今回読んでいない。数値は記憶であり、実物と違いうる。**

確信の度合い: ［高］＝公式仕様（Steamworks の画像規格）や広く知られた事実、［中］＝観察の記憶で、おおむね確か、［低］＝推測。対象は、2019 年の「Your Store」の改修から 2023 年ごろまでのストアの画面。

## (a) 画面の骨格

**幅**［高］: 中央に 1 列で、本文の幅は 940px に固定。ダークテーマが既定で、ライトテーマは無い。

**全体のナビゲーション（最上段）**［高］: 高さ約 104px、背景 #171a21。ロゴと「STORE / COMMUNITY / SUPPORT」（大文字 14px、灰色 #b8b6b4）が並び、右上に緑の「Install Steam」がある。

**ストアのサブナビゲーション（2 段目）**［高］: 高さ約 35px。「Your Store / New & Noteworthy / Categories / Points Shop / News / Labs」。**「Categories」にポインターを合わせるとメガメニュー**が開き、「Special Sections（Free to Play・Early Access・VR…）／Genres（Action・RPG・Strategy…）／Themes（Horror・Sci-Fi…）／Player Support（Co-op・Singleplayer…）」の 4 列が出る。右端に検索欄（"search"）と「Wishlist (N)」「Cart」がある。

**トップページ（上から）**［高］:
1. **Featured & Recommended**: 見出しは 14px の大文字。幅 940px の大カードが 1 枚で、左右に矢印、下に点があり、自動で切り替わる。
2. **Special Offers**: 3 列。緑の割引ラベルと "Ends in N days" が付く。
3. **Browse by category**: 横に並んだタイル（画像に暗いグラデーションをかけ、左下に白い文字）。
4. **4 つのタブで切り替える一覧** "NEW & TRENDING / TOP SELLERS / POPULAR UPCOMING / SPECIALS"。**左の約 620px が 15 行ほどの行のリスト、右の約 300px が、ポインターを合わせている作品のプレビュー**（スクリーンショット 4 枚・タグ・レビューの要約）［中］。
5. 以降は「Discovery Queue」「Popular Curators」「Recently Updated」…と続く。**下に行くほど、利用者ごとに合わせた内容（個人化）が強くなる**。

**一覧ページ（検索・タグ）**［高］: 結果は**カードではなく行**で示す。左が行のリスト（約 620px）、右が絞り込みの縦のパネル（約 300px。価格のスライダー／tag／feature／OS／言語を折りたたんで並べる）。上に並べ替えのプルダウン（Relevance / Release date / Name / Lowest price）がある。下へスクロールすると続きが読み込まれる（無限スクロール）。カテゴリーのページは、大きなカルーセル →「Popular subcategories」のチップ → 4 つのタブで切り替える一覧、の順［中］。

## (b) カード 1 枚の構成

**Featured の大カード**［高］: 左に **616×353px のヘッダー画像**（"Main Capsule" の規格）、右に約 300px の情報の列。情報の列は、上から題名（白、20px 前後）→ **理由を示す一行**（"Now Available" / "Top Seller" / "Recently Updated" / "Recommended by your friends" を小さな大文字で）→ 小さなスクリーンショット 2×2（それぞれ 155×87 ほど）→ 右下に**価格ブロック**。角丸も影も無い。

**4 つのタブで切り替える一覧の 1 行**［中］: 高さ約 69px。184×69 の小さなカプセル画像 → 題名（白、14〜15px）と OS のアイコンと**上位のタグ 3 つ**（灰色、11px）→ 右端に価格。ポインターを合わせると、**背景が明るい青灰色（#c6d4df 前後）に反転し、文字が濃紺**になる。

**検索結果の 1 行**［高］: 高さ約 45〜50px。120×45 の細長いサムネイル → 題名（白、14px）と発売日（灰色、11px）→ レビューの要約を示す親指のアイコン → 右端に価格ブロック（約 130px）。カード型の 3〜4 倍の密度になる。

**価格ブロック（共通）**［高］: 割引率のラベルは**背景 #4c6b22、文字 #beee11（黄緑）**の太字。元の価格は灰色 #738895 で取り消し線を引き、最終価格は、割引中なら黄緑、通常は薄い白。無料なら、価格の位置に "Free" / "Free To Play" と出る。**状態を示す帯**（"IN LIBRARY" は緑、"ON WISHLIST" は青灰色）は、**カプセル画像の右上**に小さく出る［中］。

## (c) 詳細ページ（製品ページ）の構成

**最初の 1 画面（上から）**［高］: **作品の画像をぼかした背景** → パンくずリスト（"All Games > Action Games > 作品名"、12px、灰色）→ **題名（26px、白）** → 2 列:
- **左 616px**: 動画／スクリーンショットの大きなカルーセル（600×338）と、その下のサムネイルの帯。
- **右 324px**: 460×215 のヘッダー画像 → 紹介文（13px、3〜4 行）→ **Recent / All Reviews**（"Very Positive (12,345)"）→ Release Date → **Developer / Publisher（リンク）** → タグのチップ 5 つ＋「+」。

**操作のボタン**［高］: カルーセルのすぐ下に、「Add to your wishlist」「Follow」「Ignore」の暗い青灰色のボタン（12px）。その下に**購入ブロック**があり、「Buy 作品名」の見出しと、右下に**緑の "Add to Cart"**（#75b022→#588a1b、白い文字 15px、角丸 2px）を置く。無料なら、同じ緑で **"Play Game"**。所有済みなら「Already in your Steam library」の青い帯が出る。**緑は「手に入れる」操作にだけ使う**。

**Early Access**［高］: 購入ブロックの上に、枠で囲んだ帯「Early Access Game — Get instant access and start playing; get involved with this game as it develops.」と "Note: This Early Access game is not complete…"、開発者の Q&A（"Why Early Access?"）を置く。一覧ではラベルを付けず、タグで示す。**区分は「買う直前」に「文章で」説明する**。

**その下の並び**［高］: DLC → About This Game（長文、14px）→ **System Requirements**（Minimum / Recommended の 2 列の表: OS・Processor・Memory・Graphics・Storage）→ More like this → Customer reviews（要約と時系列の棒グラフ。各カードに、アバター・"Recommended"／"Not Recommended" の親指のアイコン・プレイ時間）。

**右の列の情報表**［高］: Features（Single-player / Online Co-op…。各行に小さなアイコン）、Languages（Interface / Full Audio / Subtitles の 3 列にチェック）、Title / Genre / Developer / Publisher / Release Date、**Steam Deck Compatibility（Verified は緑のチェック / Playable は黄色の i / Unsupported は灰色の ⊘）**。

## (d) 文字

- 書体は自社の **Motiva Sans**（Light / Regular / Medium / Bold）で、代替は Arial［高］。
- **本文の基準は 12px**［高］。題名 26px、節の見出し 14px の大文字、行の題名 14〜15px、補足・タグ 11px、長文 14px［中］。行間は約 1.4〜1.5［低］。
- 見出しはほぼ**すべて大文字**（"ABOUT THIS GAME"）。太さではなく、大文字にすることで階層を表す［高］。

## (e) 色

- ページの背景は **#1b2838**、最上段のナビゲーションは **#171a21**、面は **#16202d** や黒 20% を重ねた色［高］。
- 文字は **#c6d4df**（青みがかった薄い灰色）、二次の文字は **#8f98a0**、控えめな文字は #556772 前後［中］。
- アクセント色は **Steam の青 #66c0f4**（リンク・好意的なレビューの要約）と**緑 #5c7e10〜#75b022**（購入・所有）。**青は「見る」、緑は「手に入れる」**を表す［高］。
- 割引は #4c6b22 / #beee11。レビューの要約は、好評 #66c0f4、賛否両論 #b9a074、不評 #a34c25［中］。
- ライトテーマは無い。製品ページだけは、作品の画像を背景に敷く［高］。

## (f) 余白・角丸・グリッド・影

- 幅 940px の一列構成。2 列にするときは 616 + 324［中］。帯と帯の間は約 30〜40px、帯の内側の余白は 16px 前後［中］。
- **角丸はほぼ 0〜2px**（ボタン 2px、チップ 2px、画像は直角）。2022 年以降の新しい部品だけが 3〜4px［中］。
- 影はほとんど使わず、**明度の差と 1px の暗い境界線**で面を分ける。ポインターを合わせたときは、白く光る縁か、面の色の反転で示す［中］。
- 画像の規格（Steamworks の公式の値）［高］: Main Capsule 616×353、Header 460×215、Small Capsule 231×87、Library（縦長）600×900。**作成者が規格どおりの画像を提出し、ストアが縮小して使う**ので、比率が崩れない。

## (g) 信頼の印と、印の無いものの見せ方

- **公式の審査済みマークは無い**［高］。Greenlight（2012〜2017）のあとは Steam Direct（登録料 100 ドル）となり、だれでも作品を並べられる。信頼を示すのは、**すべて後から付く、評判や第三者による印**である: レビューの要約の語（Overwhelmingly Positive〜Negative の 9 段階）と件数／Featured の「理由を示す一行」／**キュレーター**（個人や媒体による "Recommended / Not Recommended" の短評。製品ページに "N curators have reviewed this product" とアバターが出る）／**Steam Deck Verified**（「Valve が実機で確認した」ことを示す唯一の印。技術的に適合しているという意味で、品質の保証ではない）／Developer / Publisher の名前がリンクとして残る［いずれも高］。
- 印の無い作品は、印が無いまま並ぶ。レビューが少ない作品には "N user reviews" とだけ出る［高］。

## (h) 探す動線

- **探す入り口は 4 つ**: 検索欄（入力中に候補が出る）、Categories のメガメニュー、タグ（どの作品からもチップで移動できる）、個人化されたおすすめ［高］。
- 絞り込みは**すべて右の縦のパネルにある**。選ぶとすぐに左の結果が更新され、選んだ条件はチップとして表示されて、× で外せる［中］。並べ替えはプルダウン 1 つ［高］。
- タグは**利用者が付け、投票で順位が決まる**。Genres は作成者が記載する。**大分類は作成者の記載、細分類は利用者の集合知**で決まる［高］。

## (i) 専門家でない利用者が迷わない工夫

- ボタンの文言を動詞でそろえている（"Add to Cart" / "Play Game" / "Add to your wishlist"）。「Buy」は見出しに置く［高］。
- 最初の 1 画面で、「題名・映像・紹介文・作成者・評判・価格」が同時に見える［高］。
- 空の状態: 検索結果が 0 件なら、"0 results match your search." と、絞り込みの解除を促す一文を出す。Wishlist が空なら "Oops, there are no items on your wishlist."［中］。
- ポインターを合わせるとプレビューが出るので、**クリックせずに 15 作品を比べられる**［高］。

## (j) 取り入れる点と、取り入れない点

**取り入れる**
- 「一覧は行、注目させたいものはカード」という使い分け。すべてをカードにはしない［高］。
- 4 つのタブで切り替える一覧と、ポインターを合わせた作品を右側に出すプレビュー。タブは「新着 / よく使われる / 更新あり」に置き換えられる［高］。
- 理由を示す一行。星が無くても、「なぜここに出ているか」を示すことで信頼を作れる［高］。
- 緑＝手に入れる、青＝見る、という色の使い分け［高］。
- Early Access の、「買う直前に文章で区分を説明する」帯。未審査（インディーズ）の見せ方に近い［高］。
- Developer / Publisher の名前がリンクとして残ること。System Requirements の 2 列の表は「対応環境」に使える［高］。
- 画像を規格どおりに提出させ、ストアが縮小して使う［高］。大分類は作成者の記載、細分類は利用者の集合知、という二層の分け方［中］。カプセル画像の右上に出す状態の帯は、「導入済み」の表示に使える［中］。

**取り入れない**
- 本文 12px の密度。専門家でない利用者には小さすぎる。基準は 14〜15px に上げる［高］。
- ダークモードに固定していること。ライトモードの無い設計は、社内ツールの出発点にならない［中］。
- 割引率を示す黄緑のラベルと、期限で購入をあおる表示。無償／有償の表示は必要だが、セールを思わせる見た目は要らない［高］。
- レビューの要約・親指のアイコン・件数を信頼の柱にする作り。代わりに、「審査済み」の印と「理由を示す一行」で信頼を示す［高］。
- 自動で切り替わるカルーセル［中］。下へ行くほど個人化され、見る人によって画面が変わる作り。社内では「だれが見ても同じ一覧」を基本にする［中］。
- 年齢確認の画面や、Mature（成人向け）の警告文［高］。
