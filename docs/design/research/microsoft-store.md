# Microsoft Store（Windows 11 アプリ／Web 版 apps.microsoft.com）の観察メモ

> **この内容は Claude の学習データ（記憶）に基づく。実物のページは今回読んでいない。数値は記憶であり、実物と違いうる。**
> ［高］＝公開されている Fluent / WinUI の設計指針の数値か、長く変わっていない仕様。［中］＝観察した記憶はあるが、数値に幅がある。［低］＝「そうだったはず」という推測。
> 対象は、2021 年に刷新された「新しい Microsoft Store」と、同時期の Web 版。2023 年以降の改訂（AI Hub、Arcade）は、記憶がはっきりしない。

## (a) 画面の骨格

- **ウィンドウ全体が Mica（壁紙の色を薄く透かした面）で、左に細いナビゲーションの帯、上に検索、右に内容を置く**［高］。タイトルバーは内容と一体になっており、右上にアカウントのアバターがある［高］。
- **左のナビゲーションは幅 60〜70px の縦の帯で、アイコンの下にラベルを置く**［中］。項目は Home / Apps / Gaming / Movies & TV で、下端に Library と Help がある［中］。**部門（Apps／Gaming）が最上位の切り替えで、その下にカテゴリーがある**という二段の構成［高］。
- 検索は上部中央の丸い入力欄。入力中は、アイコン付きの候補が出る［高］。
- **Home**: ①横長の画像の特集（ヒーロー。自動で切り替わる）②「Top free apps」「Essential apps」「Featured collections」などの横並びの一覧（横にスクロールする）。一覧の右端に「See all」と矢印がある［高］。
- **Apps／Gaming**: 部門のヒーロー → カテゴリーのチップ（Productivity / Developer tools / Photo & video …）→ Top free / Best-selling / Top rated の一覧［中］。
- **一覧（See all やカテゴリーから開く画面）**: 上にフィルターのドロップダウン（Type・Price・Rating）、その下は縦に伸びるグリッド。順位付きの一覧では、左に順位の数字が付く［中］。
- **Web 版**: 上に横に並んだタブ（Home / Apps / Games / Movies）と検索がある。製品ページの URL は `/detail/<製品ID>` で、ボタンを押すとアプリ版のストアが `ms-windows-store://` で開く［高］。

## (b) カード 1 枚の構成

- **一覧の標準のカード**（上から）: ①アイコン（角丸の正方形 64〜96px。**アイコンの背景色を四角い板として敷く**）②名前（Body Strong、2 行を超えると省略）③"4.6 ★" ④価格（"Free" / "Free+" / "¥1,150"）［中］。縦長で、幅 180〜230px、内側の余白 12〜16px、角丸 8px。面は Layer で、1px の薄い枠が付く［中］。
- **ゲーム・特集のカード**: 上に 16:9 の画像を置き、その左下に小さなアイコンを重ね、下に名前と価格を置く。画像の左上に、「Game Pass」「Xbox」の黒地に白い文字のバッジが付く［中］。
- **順位付きの、行の形をしたカード**: 順位 → アイコン（48〜64px）→ 名前／発行元／星 → 右端に価格と「Get」［中］。
- **価格は文字だけで示す**。"Free" は通常の太さ。アプリ内課金があれば "Free+" と書き、詳細ページでは "Offers in-app purchases" と示す［中］。
- 年齢区分（EVERYONE / PEGI / CERO）は、詳細ページでだけ白地の小さな箱で示す［中］。ポインターを合わせると面がわずかに明るくなり、影は増えない［中］。

## (c) 詳細ページの構成

- **最初の 1 画面**: 左に幅 300px 前後の列［低］、右が本文。
  - 左の列（上から）: 大きなアイコン（128px 前後）→ タイトル（Title 28px、SemiBold）→ 発行元の名前（リンク）→ 星と件数、カテゴリー → **価格の文字と主ボタン**（列いっぱいの幅）→ "Offers in-app purchases" → 年齢区分 → 対応デバイスのアイコン［中］。
  - 右の本文（上から）: 横にスクロールするスクリーンショット（1 枚 320〜400px）→ Description（折りたたまれ、"Show more" で開く）→ Features → What's new → Ratings and reviews（評価の分布の棒、"Rate and review"）→ **Additional information**（項目名と値を 2〜3 列で並べる）→ People also like → Report this product［中］。
- **ボタンは一つで、文言が状態を表す**: "Get"（有料なら価格を添える）→ "Install" → 進捗リング → "Open" → 更新があれば "Update"［高］。色は Windows のアクセントの青で、白い文字、角丸 4px、高さ 32px［高］。
- **Additional information の項目**: Published by / Developed by / Release date / Approximate size / Category / **This app can**（権限を平易な文で示す: "Access your Internet connection"）/ Installation（最大10台）/ Supported languages / Publisher info / Report this product［高］。

## (d) 文字

- **Segoe UI Variable**（小さい文字は Text 軸、大きい文字は Display 軸）。日本語は Yu Gothic UI で表示される［高］。
- WinUI の文字の段階（size/line-height/weight）［高］: Caption 12/16、Body 14/20、Body Strong 14/20 SemiBold、Body Large 18/24、Subtitle 20/28 SemiBold、Title 28/36 SemiBold、Title Large 40/52、Display 68/92。
- ストアでの使い分け: カードの名前＝Body Strong、価格・発行元＝Caption の第二の文字色、一覧の見出し＝Subtitle、詳細の題名＝Title［中］。**太さは Regular と SemiBold の 2 段階だけ**［高］。

## (e) 色

- **ウィンドウの背景は Mica**。ライトモードでは #F3F3F3 に壁紙の色味が加わり、ダークモードでは #202020 前後［高］。
- **面（Layer）**: ライト #FFFFFF α0.7、ダーク #FFFFFF α0.054。枠線はライト rgba(0,0,0,0.058)、ダーク rgba(255,255,255,0.083)［高］。
- **文字**: ライトの第一の文字色 rgba(0,0,0,0.896)、第二 rgba(0,0,0,0.606)。ダークの第一 #FFFFFF、第二 rgba(255,255,255,0.786)［高］。
- **アクセント色**: ボタンの塗りはライト #005FB8、ダーク #60CDFF（ダークでは文字が黒）。システムの既定は #0078D4 で、壁紙に合わせて変わる［高］。
- **ダークモードへの対応**は、色を 2 組持つのではなく、α で定義した階層を暗い基調の上に重ねる方式［高］。

## (f) 余白・角丸・グリッド・影

- 4px を基準にし、刻みは 4 / 8 / 12 / 16 / 24 / 32 / 40［高］。
- 角丸: **ウィンドウと上位の面（カード・フライアウト）は 8px、内側の部品（ボタン・入力欄・行）は 4px**［高］。
- 内容の左右の余白は 40〜48px、一覧どうしの間は 32〜40px、カードの間隔は 12〜16px［中］。
- 影: **カードには通常ほぼ影が無い**（枠線と面の明るさで浮かせて見せる）。影（elevation）が付くのは、フライアウトとダイアログだけ［高］。

## (g) 信頼の印と、印の無いものの見せ方

- **「審査済み」の印は前面に出ない**。ストアに並んでいること自体が審査済みを意味し、①発行元の名前 ②年齢区分 ③「This app can」の権限の一覧 ④アカウントごとに最大10台、で信頼を組み立てる［高］。
- 発行元が自前のインストーラーで配る Win32 アプリも並んでおり、その場合は Additional information に「This app is provided and updated by <発行元>」という一文が入るだけ［中］。**同じ一覧に並べ、詳細ページの一文で区別する**ため、一見しただけでは分からない［中］。
- Editors' choice のような常設のバッジは無く、「Spotlight」「Featured collections」「Microsoft Store Awards」といった一覧の名前で、編集部のおすすめであることを示す［中］。
- 「Microsoft 製」の印は無く、発行元の名前が文字で出るだけ［中］。

## (h) 探す動線

- 主な探し方は、上部の検索（入力中に候補が出る）。結果の画面では、上にフィルター（Type / Price / Rating）があり、部門ごとに区切られる［中］。
- 部門のページのチップから、カテゴリーの一覧へ進む［中］。横並びの一覧の「See all」から、全件の一覧へ進める［高］。
- Web 版は URL に製品 ID を持つので、**共有されたリンクがそのまま入り口になる**［高］。
- 企業向け: 旧 Store for Business の「プライベートストア」は、**上部のタブに会社名がそのまま並ぶ**形だった（2023 年に廃止され、Intune に移った）。一般向けのストアの中に、自社専用のタブが一つ増えたように見える［中］。

## (i) 専門家でない利用者が迷わない工夫

- ボタンが一つで、文言が状態を表す（Get → Install → Open）。「ダウンロード」と「インストール」を分けない［高］。
- 最初の 1 画面の左上に、アイコン・名前・作成者・価格・ボタンの 5 つがまとまっている［高］。
- 読み込み中は、カードの形をしたスケルトンを出す。ただし、**読み込みが遅く、スケルトンが長く残る**のが最大の不満点［中］。空の状態は、一文と戻るリンクだけ［低］。

## (j) 取り入れる点と、取り入れない点

**取り入れる**
- **Mica＋Layer＋1px の枠で作る「静かな面」**。影ではなく透明度の階層で浮かせて見せるので、暗い基調にもそのまま移せる。社内の Windows 環境で、ストアらしく見せる最短の方法［高］。
- **一つのボタンの文言で状態を表す**（入手／開く／更新）。金額は文字で示し、無償を太字にしない［高］。
- **部門 → カテゴリー → 一覧の二段の構成**。左のナビゲーションの上段に「オフィシャル」「インディーズ」、その下にカテゴリーのチップ、という形がそのまま骨格に使える［中］。
- **Additional information の表**。作成者・公開日・サイズ・カテゴリー・できること・連絡先・報告のリンク。作成者の名前を残す場所として最も自然［高］。
- **アイコンを色の板の上に置く**。質がばらつく社内の成果物でも、そろって見える［中］。
- **製品 ID を URL に持つ**［高］。

**取り入れない**
- **星とレビュー**。件数が少ない社内では、"4.5 ★ (3)" のような意味の薄い数字になる［高］。
- **自動で切り替わるヒーロー**。落ち着いて読めない。置くなら固定の 1 枚にする［中］。
- **審査の有無を、詳細ページの一文だけで区別する**やり方。オフィシャル／インディーズは、一覧の段階で分ける［中］。
- **目的の違うもの（Movies、広告）を同じ一覧に混ぜる**こと［中］。
- **長く残るスケルトン**。社内の成果物は数が少ないので、一覧は最初から全件を読み込んで表示する［中］。
- "Free+" のような記号。「無償」「有償（¥…）」と文字で書く［中］。
