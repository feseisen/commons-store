## 5. マイクロインタラクション（`prefers-reduced-motion` のときはすべて 0）

- **行**: ホバーで `--fill` の半分の濃さ、120ms。押したとき `scale(.99)`。**B・C・D・E**: ホバーで `scale(1.015)`＋影 `0 12px 28px rgba(0,0,0,.16)`、200ms
- **ピル**: 押すと 900ms の進捗リング（28、線 2）を出し、「開く」（ツール）／「入手済み」（素材）に変える。`localStorage['store.got']` に記録し、トースト「『月次集計の計算表』を入手しました」。有償なら先にシート（幅 420、`--r-card`）を出す: 「利用の申し込み」、「¥5,000（1部門あたり月額）」、費用の付け替えの説明＋青ピル「申し込む」＋「キャンセル」→トースト「『月次集計の計算表』の利用を申し込みました」
- **詳細**: ルートが変わったら 160ms でフェードし、アイコンは `.96→1`、ページの先頭へ移る。戻るときは `history.state` の位置に戻す。見出しが隠れたら、帯にアイコン 32・名前・ピルが 200ms で滑り込む［高］
- **一覧の横送り**: `scroll-snap-type:x mandatory`、1 ページ＝2 列×3 行、右端に次の列が 24px のぞく。**≥1024 は見出しの右端に ‹ › の丸ボタン 28 を常に出す**（ホバーしたときだけ出す型は、Windows でマウスを使う人には見つけにくい）
- **見出しの縮小**: large の直後に高さ 1 の番兵の要素を置き、`IntersectionObserver` で画面から外れたら帯に `.is-compact` を付ける（120ms）。**segmented**: 白い thumb が 200ms で滑る。**トグル**: 51×31、ON は accent
- **トースト**: 上部中央のカプセル型 44h、表示は 2.4 秒、同時に出すのは 1 枚。**フォーカス**: accent 2px の outline、offset 2。Esc でシート・候補を閉じる

## 6. 実装で陥りやすい罠と、その避け方

1. **並べ替えが印を参照してしまう。**全画面で 1 か所の `sortByUpdated()` を使い、`signals` は比較しない
2. **白文字を載せる面の色が薄くなる。**明度は 4 章の表か `faceL()` だけで決め、L を直書きしない
3. **`hashchange` が届かない。**クリックは `router.go(path)` を通し、hash の書き込みと描画を分ける。起動時は hash、sessionStorage の順に見る
4. **`<use>` の id が衝突する。**symbol の id は `sym-<shelf>` にし、成果物ごとに `<svg>` を複製して参照する
5. **ダークモードで、影に頼った要素が見えなくなる。**影は `--shadow` 経由でだけ付ける。ダークでは none になり、`--ring` が代わりを務める
6. **3 行目が折り返す。**省略するのは左側だけにし、右の理由の一語は `flex-shrink:0` にする。日付は `T00:00` を付けてローカル時刻として解釈する
7. **returned が漏れる。**利用者の画面では none と同じに扱う。`note` を見られるのは `#/mine` と審査待ちの画面だけ
8. **Google Fonts が読み込めず、文字の高さがずれる。**`line-height` は絶対値で指定し、Segoe／Yu Gothic UI で幅 1280 と 400 を確かめる
9. **公開のフォームを描き直すと、入力が消える。**状態を 1 つのオブジェクトに持ち、プレビューだけを描き直す

## 7. 受け入れ基準（満たさなければ不合格）

1. 1 枚の HTML で、外部から読むのは Google Fonts だけ。`<img src="http…">` と外部 JS は 0
2. **すべての成果物にアイコンがある**。ツールは濃い面、素材は紙色で、8 つのカテゴリーの記号が対応表どおり
3. UI は無彩色＋`--accent` 1 色。赤・橙・黄・緑が `<style>` に無い（`hsl()` の面は除く）
4. **行カードの印は「✓ 審査済み」1 つまで。**区分のページでは出さず、区分を混ぜて出す画面でだけ出す
5. 文字サイズは 34／28／22／17／15／13／11 の 7 段、太さは 400 と 700 だけ、12px 未満は cap だけ
6. **どの一覧も `updated` の降順。**sort 関数が 1 つだけで、`signals` を比較する式が無い（grep で確かめる）
7. ホームに Today（f-1）・区分のタイル 2・カテゴリーのタイル 8・コレクション（f-2）がある。`features` を空にしても崩れない
8. 左 4px の色線の帯・KPI タイル・alert 型の箱・「（試作: …）」のような内輪の注記が無い。区分を示すのは `tiers[].sub` の灰色の 1 行だけ
9. 詳細は `#/item/…` の URL を持つページである。主ボタンは 1 つで、文言は「入手／¥5,000／開く／入手済み」。**インディーズの説明ボックスが主ボタンより前**（DOM 順）にあり、黄・赤を使わない。returned が利用者に見えない

11. 白文字を載せる面すべてで 4.5:1 以上、アイコンの白の線画は 3:1 以上（f-2 hue160 と spreadsheet を必ず測る）
12. 検索が空でもカテゴリー名のチップ＋「最近の更新」を出し、0 件なら 2 行＋一覧を出す。placeholder は「名前・作成者・カテゴリーで検索」
13. 公開のフォームに「オフィシャルにしたい」のラジオボタンが無く、末尾のトグルで主ボタンが「インディーズに公開する／公開して審査を申請する」に切り替わる。カテゴリーは 8 枚のタイルから選ぶ
14. ダークモードで影が 0 になり、`--ring` の枠が付く。紙色のアイコンの面が白く光らない。`data-theme` と `prefers-color-scheme` の両方で切り替わる
15. 幅 400px で横スクロールが無い。下タブは 5 つ、詳細の主ボタンは下の固定バーにある。「公開する」が下タブを開かずに押せる。押せる要素は 44×44 以上

17. Google Fonts の `<link>` を外しても、文字サイズ・行の高さ・レイアウトが崩れない。`prefers-reduced-motion` のときは動きが 0、Esc でシートが閉じる
