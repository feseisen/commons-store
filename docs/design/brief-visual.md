# 視覚の体系 — 社内の成果物ストアへの指針

**この内容は Claude の学習済みの知識に基づく。実物のページは今回読んでいない。数値は記憶によるもので、実物と違いうる。**

材料は `research/` の 14 件である（同じく記憶に基づく）。確信の度合いは項目ごとに［高］［中］［低］で示し、公式ガイドライン（Apple HIG／Material 3／Fluent 2）と公開仕様の数値を「事実」、各ストアの画面についての記憶を「推測」として分けた。扱うのは視覚の体系（文字の段階・色・余白・角丸・グリッド・影・アイコンとサムネイル・ダークモード）だけである。前提は次のとおり: 会社の PC は Windows（Microsoft Store を調べたのもこの前提による）、星とレビューは置かない、区分はオフィシャルとインディーズ、無償／有償を明示する、作成者の名前は残す、依頼者の言う「しょぼくない」の基準は App Store の側にある。

## 1. 世界のストアに共通する法則

1. **文字の太さは 2 段階、大きさは 7 段階前後。**［高］App Store は Bold／Regular、Microsoft Store は SemiBold／Regular、Play は 500／400、Notion・Figma は 600／400。大きさは 11〜13（補足）／14〜17（カードの名前・本文）／20〜22（横並びの一覧の見出し）／22〜32（詳細のタイトル）の 4 つの範囲に収まる。段階を増やしている ThemeForest・AppExchange ほど、詰まって古く見える。
2. **本文の基準は 14〜16px。12〜13px は専門家向けであることの表れ。**［高］Steam 12、VS Code 13、Atlassian 12〜14 は開発者・管理者向けのストアである。一般向けは Slack 15〜16、Hugging Face・Notion 16。
3. **UI は無彩色とアクセント 1 色で作り、色は中身に譲る。アクセント色は、面の塗りと文字色の 2 段階で使い分ける。**［高］App Store は白・灰・青 #007AFF、Play は緑 #01875F、Microsoft Store は青 #005FB8、Figma は青 #0D99FF（ブランドの 5 色は UI に使わない）。押せる所以外には色が無い。App Store の GET ボタンは、一覧では灰色の面 #E5E5EA に青い文字、詳細では青い面に白い文字で、これが青があふれない理由である［高〜中］。2 色を使い分けているのは Steam（青＝見る／緑＝手に入れる）だけ。
4. **影は通常時ほぼ使わない。面は 1px の罫線か明度の差で分ける。**［高］Play は影なし、Microsoft Store は Layer（白 α0.7）＋1px の枠、Figma・Hugging Face は 1px の罫線、Steam・Fab は明度の差。影を使うのは、App Store の Today のカード（y 8〜10・ぼかし 20・黒 12〜20%［中］）、ホバー時（Notion 0 2px 8px .08［中］）、ダイアログだけ。
5. **角丸の大きさで「消費者向けのストア」と「業務ツール」が分かれる。**［中］App Store 13〜16、Setapp 12〜16、M3 の card 12 が前者、Atlassian 3、VS Code 2、Unity 4、Steam 0〜2 が後者。値は「外側の面／中の画像／部品」の 3 つと、両端を完全に丸めたピルがあれば足りる。
6. **アイコンの角丸はストアが一律にかけ、作成者には角の無い正方形を提出させる。**［高］Play は 512×512 に辺の 20% のマスクをかける（角丸を画像に焼き込むことは 2019 年に禁止）。iOS は辺の約 22.4% の連続曲線、macOS は 1024 の中の 824 に角丸 185.4px。ストアが一律にかけることが、提出される素材の質がばらついても一覧の見た目がそろう最大の理由である。寸法は 3 段階: 一覧 48〜64（App Store 64、VS Code 42、Slack 48）、グリッド表示 96（Play）、詳細 118〜128（App Store 118、Microsoft Store 128）［高〜中］。
7. **サムネイルはストアが縦横比を決め、その規格で提出させる。**［高］Figma 2:1（1920×960）、Unity 3:2（420×280）、Steam 616×353／460×215、Chrome ウェブストアのスクリーンショット 1280×800。比率が混在する Canva だけが masonry の配置になり、比べにくい。画像が無いときの既定の表示を持っているのは、Microsoft Store（アイコンの背景色を四角いタイルとして敷く［中］）と Hugging Face Spaces（2 色のグラデーション＋絵文字［中］）。
8. **グリッドは 4px 刻み、余白の基本単位は 16、行の高さは 60〜80。**［高］M3 は 4dp（マージン 16/24）、Fluent は 4px（4/8/12/16/24/32/40）、Slack・Atlassian はカードの内側 16。カードの間 16〜24、横並びの一覧どうしの間 32〜40、本文の最大幅 1200〜1280［中］。行の高さは App Store 約 80、M3 72、VS Code 62。Steam の 45〜50 は詰まりすぎ［中］。
9. **詳細の情報バーは「値 20／ラベル 11・大文字／縦線」、情報欄は「左にラベル（黒）・右に値（灰）・グループの角丸 10」。**［高］App Store の横にスクロールする情報の行と Information の表、Play の「大きい数値＋小さい説明」。見出しの上に添える小さな見出し（アイブロウ）は 11〜13px・大文字・字間を広め・1 色［中］。
10. **ダークモードは別のパレットとしてではなく「同じ役割の色の暗い値」として持ち、影を消す。**［高］Mac は label／secondaryLabel／fill、Fluent は暗い基調に白 α0.054 の Layer と白 α0.083 の枠、VS Code はすべてトークン。面の段階は iOS #000／#1C1C1E／#2C2C2E、Fluent #202020、VS Code #1f1f1f／#181818／#2b2b2b。アクセント色は明るくする（#007AFF→#0A84FF、#005FB8→#60CDFF。後者は文字を黒にする）。Web のストアの大半（Chrome ウェブストア・npm・Slack・Atlassian・Notion・Figma）はダークモードを持たない［中］。

## 2. そのまま持ち込む指針（数値つき）

骨格は M3／Fluent の公開仕様（4px 刻み、押せる要素の大きさの目標 44〜48）を土台にし、見た目（角丸・ピル・文字の段階）は App Store に寄せる［方針は中］。書体は system-ui を指定し、Windows では Segoe UI Variable（日本語は Yu Gothic UI）で表示されるようにする［高］。壁紙を透かす Mica は Web では再現できないので、Fluent から取り入れるのは α の階層と刻みだけにする［高］。

**文字の段階（px／行送り。太さは 400 と 600 だけ）**［段階の値は HIG・M3・Fluent を合成したもので高、当てはめは中］
- 大見出し 28/36・600 ／ 詳細のタイトル 24/32・600（最大 2 行）／ 横並びの一覧の見出し 20/28・600、その右端の「すべて見る」15・400・アクセント色
- カードの名前 15/20・600（行の形では 1 行、グリッド表示では 2 行で省略）／ 本文 15/24・400（行間 1.6［低］）／ サブタイトル 13/18・400・第二の文字色
- アイブロウ・情報のラベル 11/16・600・大文字・字間 0.06em。11px はこの 2 か所だけで、ほかに 12px 未満の文字は置かない

**色（ライトモード）**［hex は公開値なので高、組み合わせは中］
- 背景 #F3F3F3（iOS のグループ背景 #F2F2F7 でも可）、面 #FFFFFF、枠 rgba(0,0,0,0.06)。文字は第一 rgba(0,0,0,0.9)、第二 rgba(0,0,0,0.6)
- アクセントは 1 色: #0078D4（Windows の既定）。iOS に寄せるなら #007AFF。使うのはどちらか 1 つ。主ボタン・リンク・選択中のタブの下線・選択中のチップの塗り以外には使わない
- 主ボタンは 2 段階: 一覧では灰色の面 rgba(120,120,128,0.12) にアクセント色の文字、詳細ではアクセント色の面に白い文字
- 赤・橙・黄は持ち込まない。「未審査」「有償」「入手済み」はすべて、灰色の面か灰色の文字で示す

**色（ダークモード）**［値は iOS・Fluent・VS Code の公開値なので高、組み合わせは中］
- 背景 #1F1F1F、面 #292929、浮いた面 #2C2C2E〜#333333［3 段目は低］。純黒 #000 は Web では黒すぎる［低］
- 枠 rgba(255,255,255,0.08)、文字は第一 #FFFFFF、第二 rgba(255,255,255,0.78)。アクセント色は #60CDFF（文字は黒）か #0A84FF（文字は白）で、ライトモードと同じ hex は使わない
- 影はすべて 0。色はトークン（`--surface` `--text-2` `--accent`）として持ち、部品に hex を直接書かない

**余白・グリッド**［M3・Fluent の値なので高、当てはめは中］
- 4px 刻み。使う値は 4／8／12／16／24／32／40／48 だけ
- 左右の余白は 16（幅 600 未満）／24（840 未満）／40（それ以上）。本文の最大幅は 1,240。左のナビは 240、詳細の右パネルは 320（幅 1,024 未満では本文の下へ移す）
- カードの内側 16、グリッド表示のカードの間 16。行と行の間は 0 にし、1px の区切り線を、左端を 16 空けて引く（inset）。横並びの一覧どうしの間 40、見出しと中身の間 12、詳細の節と節の間 32
- 押せる要素は最小 44×44。行の高さは 72（アイコン 48）か 80（アイコン 64）

**角丸（3 つの値＋ピル）**［App Store・M3・Fluent の値なので中］
- 外側の面（カード・パネル・ダイアログ）16 ／ 中の画像 8、情報欄のグループ 10 ／ 部品（チップ・入力欄・副ボタン）8。主ボタンと検索窓は両端を完全に丸める
- アイコンの角丸は辺の 22%（48→11、64→14、96→21、120→26）。`border-radius: 22%` で近似し、連続曲線までは再現しない［低］

**影**［中］
- 通常時は 0。ホバー時は 0 2px 8px rgba(0,0,0,0.10)。特集の大カードだけ 0 8px 20px rgba(0,0,0,0.12)。浮いて表示される物（メニュー・ダイアログ）は 0 8px 24px rgba(0,0,0,0.16)。ダークモードではすべて 0

**アイコンとサムネイル**［規格は Play・Figma・Chrome ウェブストアの公開値なので高、既定の表示の作りは中］
- アイコンは 512×512・角なし・不透明の正方形で提出させ、ストアがマスクをかける。影や角丸を焼き込んだ画像は受け付けない。表示の大きさは、行の形で 48 か 64、グリッド表示で 96、詳細で 120
- サムネイルは 16:9 に固定する（推奨 1920×1080、最低 1280×720）。masonry にはしない。スクリーンショットは 1920×1080 か 1280×800 で、5 枚まで
- 画像が無いときの既定の表示を先に作る: アイコンの主な色を敷いた 16:9 の背景の中央に、アイコンを 64 で置く。アイコンも無ければ、頭文字 1〜2 字（28px・600・白）を 2 色のグラデーションの背景に置く
- バッジはカード 1 枚に 1 つ。名前の直下か画像の左上に、文字のラベル（11px・600）で置く。色付きのリボンは使わない

**部品の寸法**［App Store・M3・Fluent の値なので高〜中］
- 主ボタン（ピル）: 行の中では 28×72・15px 600。詳細では高さ 40 で、右パネルの幅いっぱいにする
- チップ: 高さ 32・角丸 8・枠 1px。選択中は薄いアクセント色の面＋チェック。検索窓: 高さ 48〜56 のピル
- 詳細の情報バー: 値 20/600・ラベル 11/600 大文字・縦線 1px・欄の幅 96〜120

## 3. 持ち込んではいけないもの（理由）

- **星の黄色（VS Code の #ff8e00 系）と 5 段階の棒グラフ**。星を置かないストアなので、星にまつわる見た目の要素ごと外す。外すと、カードの縦の詰まりが 1 段軽くなる（Unity の観察）［高］
- **セールを表す見た目の要素**。Steam の割引ラベル（#4c6b22／#beee11）、Unity の「-50%」、取り消し線、カウントダウン。社内に値引きは無く、暖色のラベルは「有償」の表示と紛らわしい［高］
- **ほかのストアのブランド色**。Hugging Face の黄橙、npm の赤、Gumroad のピンク、Canva の紫、Envato の緑。アクセントは 1 色と決めているので、2 色目を入れる余地は無い［高］
- **「未審査」を警告色で示すこと（AMO の淡黄色のボックス）**。Steam の早期アクセスのボックスは、色ではなく文章で区別する型である。取り入れるならボックスの形だけにし、黄色は使わない［高］
- **12〜13px の本文と 2〜4px の角丸（Steam・Atlassian・VS Code・Unity）**。管理画面のような密度になり、「しょぼくない」から遠ざかる［高〜中］
- **純黒の背景と、ダークモードへの固定（iOS の #000、Steam・Fab の黒地）**。Web の面は #1F1F1F の側に寄せて明るくし、ライトモードを既定にする［低〜中］
- **黒い枠のブルータリズム（Gumroad）**。社内のほかの画面と調和しない。取り入れるなら値札の五角形だけ［中］
- **masonry（Canva）と、縦横比の違うサムネイルの混在（Elements）**。種類の違う成果物を比べるストアなので、比率は 1 つに固定する［中〜高］
- **文字だけのカード（VS Code・npm・PyPI）**。アイコンすら無いとストアに見えない。少なくともアイコン 48 を左に置く［高］
- **画像に文字を重ねる大カード（App Store の Today、Steam のカテゴリーのタイル）**。scrim と作画が必要で、画像が無いと崩れる。文字を画像に重ねず、画像の上側に分けて置く App Store の Apps タブの型を採る［中］
- **カード 1 枚にバッジを 2 つ以上、ボタンを 2 つ以上置くこと（Atlassian のバッジの重ね掛け、NN/g）**。複数のバッジを並べるのは詳細ページの表にし、カードには 1 つだけ［高〜中］
- **意味を覚えないと読めない記号**。Canva の王冠、Microsoft Store の「Free+」、npm の p/q/m の棒。「無償」「有償 ¥…」「入手済み」と文字で書く［中〜高］

## 4. 迷ったときの判定

1. **色を付けようとしている物は押せるか**。押せないならアクセント色を使わない。差は灰色の濃さで付ける
2. **それは浮いているか**。浮いて表示される物（メニュー・ダイアログ・ホバー中の物）だけが影を持つ。並んでいる物は、枠と明度の差で分ける
3. **画像の無い成果物で表示して、崩れるか**。崩れる部品は採らない。既定の表示（アイコン＋色の面、頭文字＋グラデーション）で先に試す
4. **新しい文字の大きさ・角丸・3 つ目の太さが欲しくなったら、実は余白の問題ではないか**。文字の大きさは 7 段階、角丸は 3 つの値＋ピル、太さは 2 段階。増やす前に、4px 刻みの余白で解決できないかを確かめる
5. **数が 3 以下で並んだとき、寂しく見えるか**。寂しく見えるなら数字は出さず、「更新日」「作成者」の文字にする
6. **ダークモードで見て、消えてしまう物は無いか**。消えた物は影に頼っていた。枠か面の段階に置き換え、部品に直接書いた hex があればトークンに直す
7. **二つの数値で迷ったら、App Store の側（大きい角丸・大きい文字・広い余白）を選ぶ**。業務ツールの密度に寄るほど「しょぼい」に近づく。ただし刻みは 4px とし、押せる要素の大きさは 44 を下回らないようにする
8. **一覧・検索結果・詳細の関連する横並びの一覧で、同じ物が同じ形で出ているか**。行の形（アイコン・名前・サブタイトル・ピル）が画面ごとに違っていたら、その画面の側が間違っている
